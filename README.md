## 專案簡介
「信運草」是一款 Android 未來信 App，使用者可以寫信給未來的自己，並在指定日期收到通知或 Email。

## 使用技術
- Kotlin
- Android Studio
- Retrofit
- Firebase Cloud Messaging
- Node.js API
- MariaDB
- Nginx / Linux VPS

## 我的負責內容
- UI 規範與主題色設計
- 資料庫
- 推播通知架構
- 同步gmail收信
- Git 分支管理
